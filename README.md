# Student Expense & Budget Management System

## Project Overview

The **Student Expense & Budget Management System** is a simple Java-based application designed to help students manage their daily expenses and monthly budget.

The system allows users to add, view, update, and delete expenses, calculate total spending, set a monthly budget, and check whether their spending is within the planned budget.

This project is developed as a **2nd-year Java project** using basic Object-Oriented Programming concepts, collections, input validation, and file handling.

---

## Problem Statement

Students often spend money on food, transportation, education, shopping, and other daily activities without keeping proper track of their expenses.

This project provides a simple computerized system where students can record their expenses and compare their total spending with their monthly budget.

---

## Objectives

* To record student expenses digitally.
* To organize expenses using categories.
* To calculate total expenses.
* To allow users to update and delete incorrect expense records.
* To set and view a monthly budget.
* To check whether the student is within the budget.
* To provide a simple and easy-to-use console interface.
* To practice Java programming and Object-Oriented Programming concepts.

---

## Features

### 1. Expense Management

The system provides the following expense operations:

* Add Expense
* View Expenses
* Update Expense
* Delete Expense
* Calculate Total Expenses

Each expense contains:

* Expense ID
* Description
* Amount
* Category

### 2. Budget Management

The system allows the user to:

* Set a monthly budget
* View the monthly budget
* Check the current budget status
* Calculate remaining budget
* Identify when expenses exceed the budget
